# Installed with --no-deps, after requirements.txt:
#   pip install --no-deps -r requirements-nodeps.txt
#
# face_recognition declares a dependency on `dlib`, and on Windows that is a
# source build that fails without CMake and a C++ compiler. requirements.txt
# provides the same library as the prebuilt `dlib-bin` wheel, but pip cannot
# tell that the two are the same thing, so installing face_recognition the
# normal way would still try to compile dlib. Everything else it needs
# (face_recognition_models, Click, numpy, Pillow) is already in requirements.txt.
